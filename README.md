# K.H. Maliwad Institute of Nursing - Official Website

**Created by: Jagdish Maliwad**

A modern, fully responsive, and feature-rich website designed for K.H. Maliwad Institute of Nursing located in Khanpur, Dist: Mahisagar. This website is built to provide a seamless digital experience for prospective students, current students, and faculty.

## 🚀 Live Preview
To view the website, simply open the `index.html` file in any modern web browser (Google Chrome, Firefox, Safari, Edge).

## ✨ Key Features

- **Modern UI/UX:** Clean medical-themed design using a Teal and Navy Blue color palette with smooth animations and glassmorphism effects.
- **Student Login (ERP) Portal:** Prominent quick-access buttons in the top bar and footer for Student, Faculty, and Parent logins.
- **Placement Partners Marquee:** A continuous right-to-left scrolling section showcasing top Civil and Private Hospitals where students are placed (e.g., Civil Hospital Khanpur, Apollo, Zydus).
- **Campus Gallery:** An interactive grid layout with hover-zoom effects and gradient overlays, showcasing the college building, advanced simulation labs, library, and student life.
- **Location & Transport Hub:** A dedicated section highlighting the institute's prime urban location with an integrated Google Map and details about full transport availability (college buses and local transit).
- **Comprehensive Course Listings:** Detailed cards for B.Sc. Nursing, G.N.M., A.N.M., and Post Basic B.Sc. Nursing.
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop viewing, featuring a hidden hamburger menu for mobile devices.
- **Floating WhatsApp Button:** Easy instant communication for prospective students.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure of the website.
- **Tailwind CSS (via CDN):** For rapid, utility-first, and highly responsive styling.
- **Font Awesome (via CDN):** For modern and scalable vector icons.
- **Google Fonts (Poppins):** For clean, modern, and highly readable typography.
- **JavaScript (Vanilla):** For the mobile menu toggle functionality.
- **Google Maps Embed API:** For accurate campus location display.
